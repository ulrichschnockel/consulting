# Mail-Cockpit für Versicherungsagenturen

Dashboard-App, die das Postfach eines Versicherungsvertrieblers analysiert, zusammengehörige Mails zu Vorgängen bündelt, kategorisiert (Schadensmeldung, Rückruf, Mahnung, …) und nach Dringlichkeit priorisiert.
